# Foodgram — продуктовый помощник

Foodgram — веб-приложение для публикации кулинарных рецептов, управления избранным и формирования списка покупок.

Проект разработан в рамках обучения на курсе «Python-разработчик» Яндекс Практикума.

## Возможности проекта

- Регистрация и авторизация пользователей.
- Создание, редактирование и удаление собственных рецептов.
- Просмотр рецептов других пользователей.
- Добавление рецептов в избранное.
- Подписки на авторов рецептов.
- Добавление рецептов в список покупок.
- Фильтрация рецептов по тегам.
- Поиск ингредиентов.
- Загрузка изображений рецептов.
- REST API для взаимодействия фронтенда с сервером.
- Административная панель Django.

## Технологический стек

**Backend:** Python, Django, Django REST Framework, Djoser.

**База данных:** PostgreSQL.

**Инфраструктура:** Docker, Docker Compose, Nginx, Gunicorn.

**Дополнительно:** Git, GitHub, Flake8.

## Архитектура проекта

Проект состоит из нескольких компонентов:

- `backend/` — серверная часть приложения, модели, сериализаторы, API и бизнес-логика.
- `frontend/` — пользовательский интерфейс.
- `infra/` — конфигурация Docker Compose и Nginx.
- `docs/` — документация API.

Серверная часть реализована на Django REST Framework. Данные пользователей, рецептов, ингредиентов и подписок хранятся в PostgreSQL.

## Запуск проекта

Для запуска необходимы Docker и Docker Compose.

1. Клонировать репозиторий:

```bash
git clone https://github.com/Katrin7828/foodgram_katrin-s.git
```

2. Перейти в директорию инфраструктуры:

```bash
cd foodgram_katrin-s/infra
```

3. Создать файл `.env` на основе `.env.example` и заполнить необходимые переменные окружения.

4. Запустить контейнеры:

```bash
docker compose -f docker-compose.production.yml up -d
```

После запуска приложение доступно на порту, указанном в конфигурации Docker Compose.

## Проверка качества кода

```bash
python -m flake8 api recipes users foodgram_backend manage.py --exclude=migrations,venv,.venv,__pycache__ --max-line-length=79
```
